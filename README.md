# ShowcaseOS — Student Skill Showcase

A polished frontend demo showcasing a student skill portfolio UI.

Quick start

1. Install dependencies

```bash
npm install
```

2. Start dev server

```bash
npm run dev
```

Open http://localhost:5173

Notes
- This project uses Vite + React + Tailwind CSS.
- The main UI is in `src/ShowcaseOS.jsx` (single default export component).
- Fonts and key animations are included inline in the component file.
- Install the `lucide-react` icons dependency for icons to render correctly.
